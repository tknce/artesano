# CROCINI 프로젝트 요구사항

## 프로젝트 개요
CROCINI(아르테사노)는 40년 경력 장인의 프리미엄 가죽 제품(크로커다일, 오스트리치, 파이톤) 브랜드 쇼핑몰입니다.

## 현재 구현된 기능

### 고객 페이지
- 메인 페이지 (히어로 섹션, 브랜드 소개)
- 상품 목록 (카테고리별 필터링: crocodile, ostrich, python)
- 상품 상세 (이미지 갤러리, 가격, 옵션)
- 브랜드 스토리 페이지
- 문의하기 (이메일 자동 발송)
- 주문제작 신청 (커스텀 옵션 선택)
- 회원가입 / 로그인 / 마이페이지

### 관리자 페이지
- 관리자 로그인 (세션 기반)
- 상품 CRUD (이미지 Cloudinary 업로드)
- 상세 이미지 관리 (다중 업로드, 순서 변경)
- 문의 내역 확인/삭제
- 주문제작 신청 확인/삭제

### 시스템
- SEO (sitemap.xml 자동 생성, JSON-LD 구조화 데이터)
- 클린 URL (301 리다이렉트)
- 보안 헤더 (Helmet CSP)
- 로그인 브루트포스 방지 (rate-limit)
- DB 자동 백업 (매일 03:00 KST → 이메일)
- Google Analytics 4 연동
- 404 커스텀 페이지
- robots.txt
