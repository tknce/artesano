# CROCINI QA 체크리스트

기능 구현 후 또는 정기적으로 실행하는 프론트엔드 품질 검사 항목.
상용 쇼핑몰(29cm, 무신사 등) 기준으로 작성.

---

## 1. 공통 리소스 로드

- [ ] 모든 HTML 페이지에서 `style.css` 로드 확인
- [ ] Toast/공통 인터랙션이 필요한 페이지에서 `script.js` 로드 확인
- [ ] 폰트(Google Fonts) 로드 확인
- [ ] favicon 로드 확인

## 2. 이미지 일관성

- [ ] 상품 카드 이미지: 동일 비율(1:1), `object-fit: contain`, 흰 배경
- [ ] 찜 목록 이미지: shop 카드와 동일 스타일
- [ ] 주문 내역 썸네일: 잘림 없이 전체 표시
- [ ] 상세 페이지 이미지: 비율 유지, 줌/라이트박스 정상 동작
- [ ] 이미지 없는 상품: placeholder 또는 빈 상태 처리

## 3. 텍스트 오버플로우

- [ ] 상품명: 2줄 말줄임 (shop 카드, 찜 목록, 장바구니)
- [ ] 상품 옵션/설명: 적절한 줄 수 제한
- [ ] 주문번호 등 긴 코드: 줄바꿈 또는 말줄임
- [ ] 가격: 천 단위 콤마 포맷 일관성

## 4. 사용자 피드백 (액션 후 반응)

- [ ] 장바구니 추가 → Toast 표시 + 뱃지 업데이트
- [ ] 찜하기/해제 → Toast 표시 + 하트 상태 변경
- [ ] 폼 제출 → 성공/실패 메시지
- [ ] 로그인/회원가입 → 결과 피드백
- [ ] 삭제 액션 → 확인 다이얼로그 + 결과 표시
- [ ] 버튼 클릭 중 → disabled 상태 + 로딩 표시

## 5. 네비게이션 일관성

- [ ] 상단 nav 메뉴 == 푸터 메뉴 (동일 페이지 링크)
- [ ] 현재 페이지 active 표시
- [ ] 모바일 햄버거 메뉴 정상 동작
- [ ] 로그인/비로그인 상태별 메뉴 표시
- [ ] 장바구니 뱃지 수량 정확성

## 6. 빈 상태 (Empty State)

- [ ] 장바구니 비어있을 때: 아이콘 + 안내 + CTA 버튼
- [ ] 찜 목록 비어있을 때: 안내 + CTA
- [ ] 주문 내역 없을 때: 안내 + CTA
- [ ] 검색 결과 없을 때: 안내 메시지
- [ ] 후기 없을 때: 안내 메시지

## 7. 에러/로딩 상태

- [ ] API 로딩 중: 스피너 또는 스켈레톤
- [ ] API 실패 시: 에러 메시지 + 재시도 안내
- [ ] 404 페이지: 존재
- [ ] 미로그인 접근 시: 로그인 페이지로 리다이렉트
- [ ] 네트워크 오류: 사용자에게 알림

## 8. 반응형/접근성

- [ ] 모바일(375px)에서 레이아웃 깨짐 없음
- [ ] 태블릿(768px)에서 그리드 조정
- [ ] 키보드 네비게이션 가능
- [ ] aria-label 적절히 부여
- [ ] skip-nav 링크 존재
