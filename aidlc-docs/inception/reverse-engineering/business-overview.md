# Business Overview — CROCINI

## 프로젝트 개요

CROCINI는 고급 이국 가죽(악어, 타조, 파이톤) 핸드백 전문 온라인 쇼핑몰이다.
도메인: `www.crocini.co.kr`

## 핵심 비즈니스 기능

| 영역 | 설명 |
|------|------|
| 상품 판매 | 카테고리별 상품 목록, 상세 페이지, 갤러리/상세 이미지 |
| 주문/결제 | 토스페이먼츠 연동 온라인 결제, 주문 상태 추적 |
| 주문제작 | Python 카테고리 상품 대상 커스텀 오더 신청 |
| 회원 | 회원가입/로그인, 마이페이지(주문내역, 찜, 문의내역) |
| 위시리스트 | 로그인 회원 상품 찜 기능 |
| 후기 | 구매 확인된 회원만 별점+코멘트 작성 (상품당 1회) |
| 문의 | 일반 문의 접수 → 관리자 이메일 알림 |
| 관리자 | 상품/카테고리/주문/문의/후기/콘텐츠 CRUD 관리 |

## 사용자 역할

- **비회원**: 상품 조회, 문의/주문제작 신청
- **회원**: 결제, 위시리스트, 후기 작성, 마이페이지
- **관리자**: 전체 백오피스 관리 (별도 세션 인증)

## 수익 모델

고급 가죽 제품 직접 판매 (B2C). 가격대 17만원 ~ 450만원.
